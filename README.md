# 잠가! 열어! 꺼!

가스안전 3분 챌린지 — 마이크로게임 옴니버스
KGS 대한민국 가스안전 AI 게임·영상 공모전 (일반부 / 챌린지 게임)

가스사고 원인 1위는 사용자 취급부주의이고, 그중 절반 이상이 이동식 부탄연소기에서 납니다.
사고는 몰라서가 아니라 **손이 움직이는 순간의 오조작**에서 납니다.
이 게임은 안전한 시뮬레이션에서 오조작이 즉시 실패로 돌아오는 경험을 3분 안에 16번 반복시킵니다.

## 실행

`index.html`을 브라우저로 열면 됩니다. 서버도 빌드도 필요 없습니다.

- 단일 HTML + Canvas 2D. 라이브러리·프레임워크 없음
- 네트워크 요청 없음 (에셋은 `asset_web/` 상대경로)
- localStorage 등 저장소 사용 안 함. 상태는 전부 메모리
- 1080×1920 기준 캔버스를 contain 스케일. 세로/가로 모두 레터박스 유지
- 터치·마우스 동일 처리 (Pointer Events)

## 구성

| 경로 | 내용 |
|---|---|
| `index.html` | 게임 전체. **산출물은 이 파일 하나** |
| `asset_web/` | 게임용 가공 에셋 (오브젝트 28 + 배경 5, 1.2MB) |
| `tools/prep_assets.py` | 원본 → 가공본 변환 (배경 제거·크롭·리사이즈·재압축) |
| `selfcheck.js` | 자체검사. `node selfcheck.js` |
| `SPEC.md` | 사양서 |
| `기획서.txt` | 기획 근거·일정 |

원본 이미지(`asset/`, 36MB)는 저장소에서 제외돼 있습니다.
에셋을 다시 가공하려면 원본을 `asset/`에 두고:

```
python tools/prep_assets.py
```

## 게임 구조

**3라운드 × 16미션.** 라운드마다 제한시간 배율 1.0 / 0.8 / 0.6.
라운드 종료 시 실패한 미션을 최대 2개까지 즉시 재출제하고, 그때만 동작을 시연합니다.
목숨이 0이 돼도 게임은 끝나지 않습니다 — 체험교실에서 아이가 중간에 튕기면 안 됩니다.

조작 5종: 탭 · 드래그 · 회전 · 문지르기 · 타이밍.

### 미션은 데이터다

새 미션 하나 = `MISSIONS` 배열에 객체 하나 + `CHECKS`에 판정 함수 하나.
연출이 필요하면 `FX`에 함수 하나. 엔진 코드는 건드리지 않습니다.

```js
{ id:'A1', hint:['can','zone'], group:'부탄연소기', cue:'빼!', check:'checkA1',
  timeLimit:5000, bgImage:'bg_camp',
  rule:'조리가 끝나면 부탄캔을 즉시 분리한다',
  successMsg:'잔열로 캔이 터질 수 있어요',
  objects:[
    { key:'can',  label:'부탄캔',     x:840, y:1240, w:180, h:300, interact:'drag', img:'01obj_can' },
    { key:'zone', label:'안전 보관함', x:540, y:1720, w:300, h:310, zone:true, img:'13obj_zone_safe' }
  ]}
```

## 사운드

전부 Web Audio 오실레이터로 직접 연주합니다. 음원 파일이 없어 저작권 확인이 필요 없습니다.
BGM은 오디오 시계 기준으로 앞 120ms를 미리 예약하는 방식이라 프레임이 밀려도 박자가 흔들리지 않습니다.
라운드별 BPM 104 → 124 → 146.
